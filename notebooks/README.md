# Final Notebooks

This directory contains the final implementation of the GW-Mamba architecture evaluated on the four benchmark datasets.

## Contents

| Notebook | Dataset |
|----------|---------|
| gw-mamba-pem3.ipynb | PEMS03 |
| GW_Mamba_PEMS04.ipynb | PEMS04 |
| gw-mamba-pem07.ipynb | PEMS07 |
| gw-mamba-pems08_baseline.ipynb | PEMS08 |

These notebooks correspond to the final version of the proposed architecture after the architecture search documented in the research report.

The complete research process consisted of more than 150 experimental notebooks exploring multiple architecture families, including:

- LSTM / GRU / CNN
- Temporal Convolution Networks
- Graph Convolution Networks
- Graph Attention Networks
- MD-GRTN
- Graph WaveNet
- Physics-informed models
- Mamba-based variants

The complete experimental history is documented in the Research Report.
